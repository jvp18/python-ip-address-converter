Python IP Address Converter

Overview
A simple Python program that converts binary IPv4 addresses into decimal dotted notation.

This project was created as part of my journey learning Python programming, networking fundamentals and subnetting.

Example

Input:
11000000.10101000.00000001.00000001

Output:
192.168.1.1
